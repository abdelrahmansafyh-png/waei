دعم الصور داخل إجابات الألعاب

كل الألعاب الآن تدعم:
- text
- image
- category أو group
- audio يتولد تلقائيًا من text فقط

مثال:
{
  "text": "أسد",
  "image": "images/lion.png",
  "category": "animals"
}

مهم:
ضع صور الإجابات داخل مجلد images داخل ملف التمبليت/اللعبة، أو استخدم رابط صورة كامل https://...
إذا كانت الإجابة صورة فقط، اترك text فارغًا أو احذفه، لكن لن يتولد صوت لها إلا إذا أضفت text.
